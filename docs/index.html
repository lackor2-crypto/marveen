Marveen

Marveen is a self-hosted AI assistant that runs on its owner's own computer. It connects to the owner's own Google account (Gmail, Drive, Calendar, Photos) only when the owner signs in and allows it.

A Marveen egy önállóan üzemeltetett MI-asszisztens, amely a tulajdonos saját gépén fut. A tulajdonos saját Google-fiókjához (Gmail, Drive, Naptár, Fotók) csak akkor kapcsolódik, ha a tulajdonos belép és engedélyezi.

Source code and issues / Forráskód és hibabejelentés: https://github.com/lackor2-crypto/marveen
